# Screenshot sources

These screenshots show the v0.2.0 notebook UI served by `npm run dev:ui` with an in-memory database and simulated runtime. Notebook text, compute balances, consumption rates and eligible machines are sample data. No Google account or Colab runtime was used.

- `home-en.jpg`: English home page and language selector.
- `notebook-en.jpg`: English editor, sample code, simulated output and manual-run attribution.
- `notebook-zh-TW.jpg`: The same notebook in Traditional Chinese with the package sidebar.

Captured from the actual browser UI at its default viewport. To refresh them, start the local demo, use the visible controls to prepare the notebook, and take new browser screenshots. Do not use private Site screenshots, credentials or user data.
