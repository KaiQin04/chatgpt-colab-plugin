# v0.2.1 — Larger saved PNG outputs

Cell outputs can now retain up to 512 KiB of PNG Base64 and text combined.
Text retains its separate 24,000-byte limit. With no other output, this allows
approximately 384 KiB of original PNG data. The notebook must display the image
as a cell output; saving a standalone file does not embed it automatically.

Notebook document reads have a 2 MiB output budget, and `.ipynb` exports have an
8 MiB output budget. These budgets exclude source code and other document
metadata. Database queries bound returned result data before it reaches the
Worker. Large omitted outputs remain available through individual run reads.
Exports include only outputs matching the saved cell version and flag omitted
outputs in cell metadata. Capture limits omit whole images and preserve the
existing truncation notice.

The release also adjusts bounded Jupyter result downloads and refreshes the UI
bundle. PNG dimension limits remain in effect; SVG output is not supported.
There is no schema migration. Previously omitted image data cannot be recovered
by upgrading alone; rerun the relevant cell if needed.

Regression coverage includes a valid PNG larger than 377,000 Base64 bytes,
Python capture, saved-result reload after a simulated runtime close, embedded
notebook export, output-budget boundaries, and individually loading omitted
results. These are synthetic checks, not a new-account OAuth or live Colab
end-to-end acceptance test.
